# @symbiomed/ui-tokens

Colours, status tones, spacing, type scale and touch target, shared by the web and mobile apps. Plain values only.

- One accent colour; five status tones (positive, info, caution, neutral, critical) following the spec's V/I/S/D/G palette. A status is always shown with its text label.
- `statusTone` maps plan status, safety events and brace link states to a tone.
- A test checks contrast: text pairs at least 4.5:1, control borders and focus ring at least 3:1.
